# 👗 Fashion Website — PHP Project

Site web dédié à l’univers de la mode, développé en PHP avec intégration front-end HTML/CSS/JS.

---

## 🚀 Description

Ce projet est un site web sur le thème de la **mode et du lifestyle**, développé avec PHP/HTML/CSS/JavaScript pour l’interface utilisateur.

Il met en avant des visuels de mode à travers une interface simple et moderne.

---

## 🛠️ Technologies utilisées

* PHP
* HTML5
* CSS3
* JavaScript

---

## ⚙️ Lancement du projet

Pour exécuter le projet en local :

```
php -S localhost:8000 -t public
```

Puis ouvrir dans le navigateur :
```
http://localhost:8000
```
